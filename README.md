# تسجيل المندوبين

تطبيق Node.js يحفظ بيانات التسجيل والصور في قاعدة SQLite واحدة. تظهر الطلبات في لوحة الإدارة من أي جهاز بعد تسجيل الدخول.

## تشغيل محلي

يتطلب Node.js 24.15 أو أحدث، وحتى الإصدار 26. خدمة Render تستخدم الإصدار المثبت في `.node-version`.

```sh
npm ci
ADMIN_PASSWORD='your-password' npm start
```

افتح `http://localhost:3000/` للتسجيل و`http://localhost:3000/dashboard.html` للإدارة. يمكنك وضع كلمة المرور التي اخترتها في متغير `ADMIN_PASSWORD`؛ لا تضعها داخل الملفات المرفوعة إلى GitHub.

## النشر من GitHub

ارفع المستودع إلى GitHub، ثم أنشئ خدمة **Render Blueprint** من المستودع. ملف `render.yaml` يجهز خدمة Node وقرصًا دائمًا للقاعدة. سيطلب Render قيمة `ADMIN_PASSWORD` عند إنشاء الخدمة؛ ضع كلمة المرور هناك. افتح عنوان خدمة Render الناتج، وليس رابط GitHub Pages. صفحات GitHub وحدها لا تشغل الخادم أو تحفظ الملفات.

قاعدة البيانات تُحفظ في `DATA_DIR/applications.sqlite` ولا تُرفع إلى GitHub. انسخها احتياطيًا دوريًا؛ حذف القرص الدائم يحذف الطلبات والصور. الحد الأقصى 8 ميجابايت لكل مرفق. النسخ القديمة المحفوظة في متصفح واحد لا تنتقل تلقائيًا إلى القاعدة الجديدة.
